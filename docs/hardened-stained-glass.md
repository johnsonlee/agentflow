# Hardened stained-glass application model

The Chemistry Lab Journal page 9 specifies three aluminium oxide, three matching stained-glass blocks or panes, and three boron trioxide, producing glass that takes longer to break. This application adds the sixteen existing stained-glass colors as hardened full blocks. Panes remain outside this implementation and remain an unmet Education feature.

The following are explicit application choices: nine shapeless crafting-table cells with one ingredient per cell; three output blocks; hand breaking time twice ordinary stained glass; generic full-block self-drop; and original procedural reinforced-border artwork. The journal does not establish the exact native layout, output count, timings, drops, blast behavior or pixels. These choices are not native parity claims. Ordinary and ordinary stained glass retain their existing shatter-with-no-drop policy.

New block IDs 32887–32902 are in the registered extended block namespace, after the existing element IDs. They are not atomic numbers or item IDs. Existing block/item IDs, element definitions, save formats and atlas addresses stay fixed. Crafting, placement, mining, inventory capacity, ground fallback and Agent ownership use their existing shared paths.

Source: https://education.minecraft.net/content/dam/education-edition/software-downloads/Chemistry-Lab-Journal.pdf (retained official document revision 2024-06-27; target-client behavior remains uncalibrated).
